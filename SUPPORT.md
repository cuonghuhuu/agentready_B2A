# Support / Hỗ trợ

For installation questions and reproducible bugs, use [GitHub Issues](https://github.com/cuonghuhuu/agentready_B2A/issues/new/choose). Read the [English README](README.md) or [README tiếng Việt](README.vi.md) first. Feedback in either language is welcome.

Include the commit or release, Node.js version, operating system, command, expected result and actual error. Redact private URLs, credentials, personal data and proprietary records.

For security concerns, follow [SECURITY.md](SECURITY.md), not public bug reports. There is no guaranteed support response time. Scanner V0.4 is an unreleased, local-only preview with known QA blockers.

---

Với câu hỏi cài đặt hoặc lỗi có thể tái hiện, gửi GitHub Issue. Ghi rõ phiên bản, môi trường, lệnh và lỗi thực tế. Không đăng bí mật, dữ liệu cá nhân hay chi tiết lỗ hổng có thể khai thác. Dự án không cam kết thời gian phản hồi.
