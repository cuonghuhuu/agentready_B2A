# AgentReady B2A — v0.3.0-alpha.1

Bản Alpha công khai của bộ công cụ open-source giúp lập trình viên tạo catalog công khai, máy đọc được, và cung cấp WebMCP chỉ đọc tùy chọn.

Điểm mới: mô hình biến thể; import file Shopify, WooCommerce Store API, JSON-LD; JSON/Markdown/JSON-LD/llms.txt; tìm kiếm theo biến thể và tiền tệ; kiểm tra công khai và thuộc tính; bảo vệ hệ thống file. CI đa nền tảng Node.js 20/22, 31 test trong Release Candidate.

Chưa kiểm chứng storefront và browser WebMCP thật. Không hỗ trợ đồng bộ live, giỏ hàng, checkout hay thanh toán. MIT. Xem [Release](https://github.com/cuonghuhuu/agentready_B2A/releases/tag/v0.3.0-alpha.1).
